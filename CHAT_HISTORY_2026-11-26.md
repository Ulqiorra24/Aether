### 2. Разбор логики работы пробного периода и исправление расчёта дней
* **Проблема:** При активации триала или обновлении подписки в приложении отображалось **42 дня**, хотя в панели 3x-ui значилось **35 дней** ($35 + 7 = 42$).
* **Причина:** Раньше формула расчета складывала `serverDays` (35 дней) и `trialDays` (+7 дней из локальных SharedPreferences) и выводила их сумму.
* **Решение:** В `MainViewModel.kt` обновлена функция `subscriptionDaysRemaining`. При наличии активной подписки с сервера ($>0$) приложение напрямую берет значение **35 дней** с сервера 3x-ui без повторного начисления +7 дней.

### 4. Комплексная отладка системы регистрации из приложения

* **Ошибка 403 (`Запрос отклонён. Откройте кабинет на сайте`)**:
  - *Причина:* Модуль `account_api.py` отклонял запросы без браузерного заголовка `Origin`.
  - *Решение:* Добавлено исключение для мобильного клиента `Aether-Android` и вызовов без `Origin`.

* **Ошибка 503 (`Регистрация временно недоступна`)**:
  - *Причина:* При инициализации `AccountAPI` в `server.py` не передавался экземпляр `xui=xui`.
  - *Решение:* Проброшен параметр `xui=xui`.

* **Повторный вызов окна ввода 6-значного кода**:
  - *Задача:* Если пользователь случайно закрыл экран с вводом кода из письма и нажимает «Получить код подтверждения» заново.
  - *Решение:* Сервер при наличии неистекшего кода в `email_verifications` возвращает `202 Accepted` с параметром `status: verification_required` и активным `challenge_id`. Приложение на обеих вкладках *(«Регистрация» и «С подпиской»)* подхватывает `challenge_id` и повторно открывает Шаг 2 (ввод 6-значного кода).

* **Ошибка 503 (`Не удалось создать профиль. Попробуйте позже`)**:
  - *Причина:* При создании клиента в 3x-ui функция `create_client` не передавала строковые поля `"id"` и `"uuid"`.
  - *Решение:* Добавлена генерация `client_uuid = str(uuid.uuid4())` и передача `"id": client_uuid` и `"uuid": client_uuid` в структуру JSON-клиента 3x-ui.

### 5. Защита от запуска VPN при истекшей подписке и фикс расчёта «Исчерпано сегодня»

* **Отображение «Осталось дней: 1» вместо `0`**:
  - *Причина:* Формула `((expire - now) / 86400000 + 1)` при истечении подписки сегодня давала целочисленное `0`, а затем прибавляла `+ 1`.
  - *Решение:* Исправлена формула в `MainViewModel.kt`:
    ```kotlin
    val diffMs = headerExpireSec * 1000L - now
    val headerDays = if (diffMs <= 0) 0 else ((diffMs + 86400_000L - 1) / 86400_000L).toInt()
    ```
* **Защита от запуска и диалог**:
  - Если оставшиеся дни равны `0` (`isSubscriptionExpired == true`), попытка запуска VPN предотвращается.
  - Появляется диалоговое окно **«Срок подписки исчерпан»** с предупреждающей иконкой замка, подробным текстом и кнопкой **«Продлить подписку»**.
